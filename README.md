# 🐍 Python Playground

A personal collection of simple Python programs written for fun, learning, and experimentation.

---

## 📁 What's in here?

This repo is my sandbox for tinkering with Python — no grand architecture, no production code. Just scripts and small programs I write when I'm curious about something or want to explore an idea.

Things you might find here:

- Small utility scripts
- Algorithm experiments
- Math and logic puzzles
- Fun mini-projects
- Concepts I'm learning or revisiting

---

## 🚀 Running any script

All you need is Python 3 installed. Most scripts have no dependencies beyond the standard library.

```bash
# Clone the repo
git clone https://github.com/bhushanudupa/PythonPlayground.git
cd PythonPlayground

# Run any script
python script_name.py
```

If a script has external dependencies, there'll be a note at the top of the file or a `requirements.txt` nearby.
